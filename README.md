# 🎬 Movie Recommender

A full-stack movie recommendation system that combines **content-based filtering (TF-IDF)** with **live TMDB data** to deliver a Netflix-style browsing experience — search, home feeds, movie details, and two flavors of recommendations (similar-by-content and similar-by-genre).

---

## ✨ Features
- 🔍 **Keyword search** with autocomplete-style dropdown suggestions and a live results grid
- 🏠 **Home feed** across categories: Trending, Popular, Top Rated, Now Playing, Upcoming
- 📄 **Movie details page** with poster, backdrop, overview, genres, and release date
- 🤖 **TF-IDF content-based recommendations** computed locally from a pre-trained similarity matrix
- 🎭 **Genre-based recommendations** pulled live from TMDB's discover endpoint
- 🛡️ **Graceful degradation** — if TF-IDF recommendations fail, the UI automatically falls back to genre-based results instead of breaking
- 🖼️ Poster grid UI with adjustable column count, built with Streamlit

---

## 🏗️ Architecture

```
┌─────────────────┐        HTTP        ┌──────────────────┐        HTTP        -┌─────────────┐
│  Streamlit UI    │ ─────────────────▶ │ FastAPI Backend │ ─────────────────▶ │  TMDB API   │
│    (app.py)      │ ◀───────────────── │     (main.py)   │ ◀───────────────── │             │
└─────────────────┘                    └───────── ┬─────────┘                   └─────────────┘
                                                  |
                                                  ▼ 
                                     ┌─────────────────────────┐
                                     │  Local TF-IDF artifacts │
                                     │  (df.pkl, tfidf.pkl,    │
                                     │   tfidf_matrix.pkl,     │
                                     │   indices.pkl)          │
                                     └─────────────────────────┘
```

- **`NLP.py`** — offline data-science script: cleans the raw `movies_metadata.csv` dataset, builds a `tags` column (overview + genres + tagline), preprocesses text (lowercasing, punctuation removal, stopword removal, lemmatization), fits a `TfidfVectorizer`, and serializes the resulting matrix + lookup tables to pickle files.
- **`main.py`** — FastAPI backend that loads the pickled TF-IDF artifacts at startup, proxies/enriches data from the TMDB API, and exposes REST endpoints for the frontend.
- **`app.py`** — Streamlit frontend that consumes the FastAPI backend, handling search, home feed, and detail/recommendation views via simple query-param based routing.

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Create a virtual environment & install dependencies

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

<details>
<summary>Minimal <code>requirements.txt</code></summary>

```
fastapi
uvicorn
httpx
pydantic
python-dotenv
pandas
numpy
scikit-learn
nltk
streamlit
requests
```
</details>

### 3. Set up environment variables

Create a `.env` file in the project root:

```
TMDB_API_KEY=your_tmdb_api_key_here
```

Get a free API key from [TMDB](https://www.themoviedb.org/settings/api).

### 4. Generate the TF-IDF model (one-time)

Place `movies_metadata.csv` in the project root, then run:

```bash
python NLP.py
```

This downloads NLTK's `stopwords` and `wordnet` corpora, cleans the dataset, and produces `df.pkl`, `indices.pkl`, `tfidf.pkl`, and `tfidf_matrix.pkl`.

### 5. Run the backend (FastAPI)
1st run main.py in one terminal and app.py in other terminal to view the website

```bash
uvicorn main:app --reload --port 8000
```

The API will be available at `http://127.0.0.1:8000` (docs at `/docs`).

### 6. Run the frontend (Streamlit)

```bash
streamlit run app.py
```

> Update `API_BASE` in `app.py` if your backend isn't running locally on port 8000.

## 🧠 How the Recommendations Work

1. **TF-IDF (content-based):** `NLP.py` builds a `tags` field per movie (overview + genres + tagline), vectorizes it with `TfidfVectorizer` (unigrams + bigrams, 50k max features), and stores the resulting sparse matrix. At request time, `main.py` computes cosine similarity between a target movie's vector and the full matrix to rank the most similar titles.
2. **Genre-based:** Given a movie's primary genre, the backend queries TMDB's `/discover/movie` endpoint sorted by popularity, giving a live, non-static complement to the local model.
3. **Fallback logic:** If a title isn't found in the local dataset or the TF-IDF lookup fails for any reason, the frontend automatically falls back to genre-based recommendations so the page never breaks.
